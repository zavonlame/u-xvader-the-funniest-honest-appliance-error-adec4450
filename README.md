Entry for [The Funniest Honest Appliance Error](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) — one line of at most 200 characters: the funniest honest error message an appliance could show.

**Entry:** "Error: I rinsed. I dried. The plate is still dirty. At this point one of us is lying, and it is not me."

The dishwasher ran the full cycle and the plate is still dirty — told flat, in the machine's own put-upon voice, with the twist that somebody is lying and it isn't the machine.

`main.ts` (Node 22, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` after checking the gate (1–200 chars, single line, non-blank).
